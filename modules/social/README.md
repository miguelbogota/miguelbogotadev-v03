# Social module

Owns the home-page contact copy and external social profile links.

## Interface

```tsx
import { SocialSection } from '@/modules/social';

<SocialSection />;
```

## Files

- `index.ts`: public module export.
- `components/social/index.ts`: social component export.
- `components/social/social.component.tsx`: contact copy and social links.
- `components/social/social.styles.scss`: social-section layout and presentation.
- `components/social/social.test.tsx`: social link and accessibility tests.
